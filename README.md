
# Logistics Week 4: Predictive Modeling and Optimization

## Project Overview
This project uses Python and Machine Learning to predict delivery times and improve logistics operations.

## Objectives
- Predict actual shipping days.
- Compare machine learning models.
- Evaluate model performance.
- Suggest logistics optimization strategies.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Dataset
A simulated dataset containing 500 logistics records is generated using Python.

Features include:
- Shipping Mode
- Order Region
- Scheduled Shipping Days
- Order Quantity
- Sales

Target:
- Actual Shipping Days

## Machine Learning Models
1. Linear Regression
2. Random Forest Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared Score (R2)
- Cross-validation MAE

## Optimization Strategies
- Early delay identification
- Better route planning
- Workload balancing
- Priority-based shipment monitoring
- Continuous model monitoring

## How to Run
Install the required libraries:

pip install numpy pandas scikit-learn

Run:

python logistics_week4.py

## Conclusion
This project demonstrates how machine learning can support delivery-time prediction and improve logistics decision-making.
